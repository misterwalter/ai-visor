# ai-visor
Local AI Code Advisor

The more I use AI, the less useful it becomes. As the tech develops it gets to be usable for more and more coding...but I'm still a better engineer than it when I'm in my element. So this project is my attempt to set up a simple analysis loop that can take Issues and PRs from github, along with comments on the PRs, and turn them into PRs, comments, and issues. It is a deliberately slow communication layer so that I can still use my brain, while benefitting from the AI's ability to get me unstuck.
